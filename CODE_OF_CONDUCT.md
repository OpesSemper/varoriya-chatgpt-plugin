# Code of conduct

Be respectful, specific, and constructive. Harassment, discrimination, threats, doxxing, and publication of another person's confidential or security-sensitive information are not acceptable.

Project discussions should focus on observable behavior, technical evidence, and user impact. Maintainers may edit, hide, or remove content and restrict participation when needed to protect contributors or the project.

Report conduct concerns privately to the repository owner. Do not use a public issue when the report contains personal or sensitive information.
